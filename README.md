# Uncovering Bias Mechanisms in Observational Studies

This repo contains code to recreate the results in the paper: "Uncovering Bias Mechanisms in Observational Studies via Predictive Performance". 

## Setup 
1. Clone the repository:\n
  ```git@github.com:clinicalml/benchmarking-os.git```\n
  ```cd benchmarking-os```\n
2. Create and activate the conda environment:\n
  ```conda env create -f environment.yml```\n
  ```conda activate benchmarking-os```\n
4. Run the tests in ```whi/``` to verify the installation:\n
  ```pytest test_main.py```\n
  ```pytest test_replication.py```\n
